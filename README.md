# Workout

A minimal, glass-inspired, local-first workout tracker and fitness journal.

## Features
- Sample dumbbell upper-body routine
- Set completion and weight logging
- Rest countdown with pause and skip
- Workout history and basic totals
- Installable PWA with offline app shell
- Data stored in this browser using localStorage

## Deploy
GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/(root)`.

## Privacy
No account or backend is used. Workout data stays in this browser on this device. Clearing browser site data can erase it; export/backup is not included yet.
